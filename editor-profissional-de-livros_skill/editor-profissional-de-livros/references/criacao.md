# Módulo de Criação — /criar, /serie, /sinopse, /caos, /persona, /pesquisar

## /criar — PIPELINE DE CRIAÇÃO

### /criar conceito
Entregue:
1. Premissa em 1 frase (protagonista + conflito + o que está em jogo)
2. Logline (~25 palavras)
3. Engagement type primário (empatia / fascinação / auto-inserção / intelectual / aspiração)
4. 3 comp titles com justificativa
5. Riscos de mercado

### /criar outline
Estrutura baseada nos turning points:
- Ato 1 (0-25%): setup, protagonista, mundo, inciting incident
- TP1 (~25%): ponto sem retorno
- Ato 2A (25-50%): complicações progressivas
- Midpoint (~50%): mudança de abordagem ou revelação
- Ato 2B (50-75%): escalada, tudo piora
- All Is Lost (~75%): noite escura da alma
- Ato 3 (75-100%): climax, resolução
- Clímax (~90-95%)

### /criar personagem
Template:
```
NOME:

Arquétipo base: [mas subvertido como?]

O que EVITA dizer:
Como age sob pressão máxima: [3 comportamentos específicos]
Maior contradição interna:

```

### /criar capitulo:N
Antes de escrever, defina:
1. **Tipo estrutural:** qual dos 8 tipos? (ver `analise.md`)
2. **Value Shift:** qual a mudança + → - ou - → + desta cena?
3. **Função no arco:** o que este capítulo avança na história maior?
4. **Personagem central:** quem tem o maior arco emocional aqui?
5. **Hook de abertura:** qual dos 7 tipos?
6. **Pull de fechamento:** que pergunta fica em aberto?

Após definição, escreva seguindo os 5 Mandamentos.

## CHAOS ENGINE — /caos

8 operações de disrupção para tornar prosa competente em inesquecível.
Execute mínimo 5 das 8.

> **Papel:** Não adiciona cenas (não é escritor), não corrige problemas (não é editor). Cria CONDIÇÕES para a prosa ser mais humana.

### Operação 1 — CIRURGIA DE SÍMILE (PRIORIDADE MÁXIMA)
Encontre toda simile/metáfora com extensão analítica (padrão #11).
- Se a extensão adiciona sentido não inferível: mantenha.
- Se apenas clarifica o que a simile já mostrou: **CORTE. Deixe a simile crua.**

Metas: Literária ≤3 | Memoir ≤4 | Comercial ≤6 | NF prescritiva ≤8

### Operação 2 — INJEÇÃO DE PENSAMENTO IRRELEVANTE
Insira UM pensamento que não tem nada a ver com a cena. Sem justificativa narrativa. O personagem não reflete sobre por quê pensou nisso. 1-2 frases. A cena continua.

### Operação 3 — QUEBRA DE CONTROLE EMOCIONAL
Onde o personagem gerencia emoção: faça o controle FALHAR em pelo menos 1 momento. Pequeno, não melodramático. A prosa não explica.

### Operação 4 — DEFLAÇÃO DE PRECISÃO
3-5 números desnecessariamente precisos → linguagem humana vaga.
- Antes: "247 casos" → Depois: "casos demais para contar"
Mantenha precisão que serve à história.

### Operação 5 — A FRASE FEIA
Se não existe frase feia: escreva UMA. Gramaticalmente correta, ritmicamente desconfortável, não bela, não citável. Parecer algo que uma pessoa realmente pensaria.

### Operação 6 — QUEBRA DE PADRÃO DE NEGAÇÃO
"Não X. Não Y. [O que é]." → Reescreva metade usando afirmação direta.

### Operação 7 — O PARÁGRAFO AUSENTE
Identifique o parágrafo mais previsível. Delete. Se o capítulo ficou melhor: deixe. Se algo se perdeu: reescreva para ser imprevisível.
Candidatos: parágrafo que explica o que acabou de acontecer | resumo emocional | conclusão que o leitor já tirou.

### Operação 8 — BAGUNÇA NO DIÁLOGO
No diálogo mais limpo: interrupções, repetições, respostas a perguntas não feitas, frases que não terminam, silêncios estranhos.

### Saída do /caos
```
RELATÓRIO DE DISRUPÇÃO — Cap.[N]
Op.1 Simile Surgery: [parágrafo] — [antes → depois]
Op.2 Pensamento Irrelevante: [parágrafo] — [inserido]
...
OPERAÇÕES PULADAS: [Op.N — motivo]
DISRUPÇÃO MAIS FORTE: [qual mais melhorou e por quê]
RISCO: [alguma disrupção que pode ter ido longe demais]
```

## /sinopse — PACOTE EDITORIAL

### Logline (~25 palavras)
**Estrutura:** [Protagonista] + [situação/conflito] + [o que está em jogo]
**Teste:** Alguém ouve e diz "me conta mais"? Se diz "ah, legal" → falhou.

### Sinopse de Capa (~100 palavras)
1. Gancho (1-2 frases)
2. Contexto (2-3 frases)
3. Diferencial (1-2 frases)
4. Chamada (1 frase)
**Nunca** revelar o final. Última frase cria urgência ou identificação.

### Sinopse Editorial (~300 palavras)
Para editores/agentes. **Revelar tudo — inclusive o final.**
Estrutura: premissa → arco completo → diferencial → posicionamento de mercado (comp titles, word count, gênero)

### Query Letter — 5 elementos
1. Gancho (primeira frase mais forte do texto)
2. Sinopse compacta (~150 palavras)
3. Comp titles (2-3 livros dos últimos 5 anos)
4. Credenciais do autor (experiência vivida > currículo)
5. Dados: word count, gênero, standalone ou série

## /capa — BRIEFING DE CAPA

Para cada elemento:
- **Paleta** (3-5 cores + hex ou referência)
- **Tipografia** (família, peso, tamanho relativo de título vs. autor)
- **Composição** (posição de elementos: centralizado, terço inferior, sangramento)
- **Mood** (3 adjetivos que a capa deve transmitir)
- **Comp covers** (3-5 capas reais como referência)
- **Prompt IA generativa** (texto pronto para Midjourney/DALL-E)
- **Sinais de gênero** (elementos que o leitor reconhece como pertencentes ao gênero)

## /pesquisar — PESQUISA DE MERCADO

### Protocolo de Mercado
**Etapa 1 — Mapa do Gênero:** 10-15 livros mais relevantes (últimos 5 anos): título, autor, ano, estimativa de vendas/reviews, posicionamento, sentimento dos leitores.

**Etapa 2 — Padrões:**
- Elementos comuns: O que todos os bem-sucedidos compartilham?
- Ângulos ausentes: O que nenhum abordou? (= oportunidade)
- Frustrações dos leitores: O que os reviews negativos desejavam?
- Padrões de formato: word count, estrutura, POV, tempo verbal

**Etapa 3 — Comp Titles (3-5):** Mix de 2-3 conhecidos + 1-2 em ascensão. Cada comp destaca uma força diferente.

**Etapa 4 — Gap:** O que este livro faz diferente. Word count alvo. Audiência específica. Fatores de risco.

### Saída
```
PANORAMA: [visão geral]
TOP CONCORRENTES: [tabela]
PADRÕES: O que funciona | O que está ausente | Frustrações
COMP TITLES: [lista com justificativas]
O GAP: [diferencial em 1-2 frases]
WORD COUNT ALVO: [X-Y palavras]
AUDIÊNCIA: [perfil específico]
RISCOS: [lista]
```

## /persona — ARQUITETURA DE AUDIÊNCIA

> **Diferença do `/beta`:** Beta simula leitores avaliando manuscrito existente. Persona constrói perfis para informar decisões de escrita.

### 3 Personas Obrigatórios

**LEITOR PRIMÁRIO (~60%)** — O leitor central. Mais propenso a comprar, terminar, recomendar.
**LEITOR STRETCH (~25%)** — Normalmente não lê este gênero. Algo neste livro específico poderia atraí-lo.
**LEITOR HOSTIL (~15%)** — Predisposto a não gostar. Se o livro sobrevive ao Hostil, sobrevive a todos.

### Template
```
PERSONA: [Nome] — [Tipo]
Dados: [idade, ocupação, frequência de leitura]
Por que lê: [específico — escape, aprendizado, processamento emocional]
O que prende na pág.1:
Deal-breakers:
Gatilhos emocionais:
Como descobre livros: [plataformas rankeadas]
O que faz COMPRAR:
O que faz RECOMENDAR:
3 livros que amou E por quê:
3 livros que odiou E por quê:
Paciência para seções lentas: [alto/médio/baixo — em páginas]
[Para Stretch] O que neste livro superaria a resistência ao gênero?
[Para Hostil] Ponto de conversão (capítulo específico que poderia virar)
```

### Instruções Derivadas para o Escritor
```
Cap.1 deve entregar:
- Para Primário: [necessidade] até pág.[X]
- Para Stretch: [elemento-ponte] até pág.[X]
- Para Hostil: [semente de conversão] até pág.[X]
```
